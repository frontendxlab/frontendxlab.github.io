Knowledge Base

Frequently Asked Questions

Concise answers regarding FrontendXLab architecture, developer tools, and open-source availability.

What is FrontendXLab?
FrontendXLab is an engineering research and development collective that creates developer tools, browser execution environments, tree-shakable algorithm libraries, and AI-driven frontend interview platforms.
What is FrontendX?
FrontendX is the flagship interview platform built by FrontendXLab. It offers comprehensive AI-assisted practice for frontend engineers, featuring data structures and algorithms in JavaScript, real-world UI implementation challenges, system design, and an integrated browser code compiler.
How do I install FrontendXLab npm packages?
FrontendXLab libraries are published under the @frontendxlab organization on npm. You can install packages such as @frontendxlab/dsa-js, @frontendxlab/agent-ui, @frontendxlab/medicons, @frontendxlab/opencode-visual-inspector, or @frontendxlab/opencode-computer-use using standard package managers such as npm, pnpm, or bun.
What is the OpenCode Visual Inspector?
OpenCode Visual Inspector is a specialized developer utility that allows engineers to click and select elements directly in a live web browser interface, annotate requested visual modifications, and dispatch structured change requests to OpenCode.
Are FrontendXLab developer tools and libraries free to use?
Yes. FrontendXLab is committed to open-source software. Our npm packages, browser runtime environments, and visual toolkits are available on GitHub and npm under permissive open-source licenses.
